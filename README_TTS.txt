LED WALL TTS

1. Replace display.html in GitHub with the new display.html.
2. Open the LED Wall Display page.
3. Tap "ENABLE TTS" once.
4. Tap TEST to confirm the speaker.
5. Leave Auto checked.
6. When a QR is scanned, the LED wall displays the participant and announces:
   "Now welcoming [name]. [position]. From [organization]. [message]."

The first tap is required because mobile/desktop browsers normally block automatic speech until the user interacts with the page.
